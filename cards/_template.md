# Name

**In one sentence:** what this scenario is.

## Preconditions
What would have to be true for this to happen.

## Timing and reversibility
Earliest plausible date. Sudden or slow-building. Can it be undone, and how hard.

## The case that this happens (or the worried case)
Two or three short quotes from named people, each dated and linked to the primary source. Then a plain-language summary of the argument, which someone on this side must sign off as fair.

## The case that it doesn't (or the optimistic case)
Same format.

## Common ground
Statements both sides would accept.

## Cruxes
Two or three questions whose answers would move each side, with a date when each can be checked.

## Probability estimates
Every published number, each with: who gave it, exact question wording, date, spread, and whether it can ever be scored. Never a number of our own. If none exists, say "no published estimate."

## Evidence confidence
Very low / low / medium / high / very high, for how solid the evidence base is. Separate from how likely.

## Signposts
Three to five observable early signs, each with a threshold.

## Evidence so far
What has already happened, with links.

## Existing coverage
Laws and rules that already apply, and whether they're enforced.

## Triage
Four steps, in order, with the reasoning shown for each:
1. Already covered by law, and enforced?
2. An action both sides accept?
3. Severe, hard to reverse, plausible within ten years, no agreed action?
4. Otherwise: communicate, with the purpose named.

**Result:** category, plus a one-line communication note.

## Related scenarios
What this leads to or combines with.

## Sign-off record
Who reviewed each side's case, and when. Changelog.
